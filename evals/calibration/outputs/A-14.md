# A-14

## Prompt

this page isn't converting. can you take a look? it's our homepage for a B2B project management tool

## Output

Happy to dig into this. A couple things first:

**I'll need the actual page** — could you share:
- The URL, or
- A screenshot / pasted copy of the page (headline, subhead, CTAs, sections in order)

**And some quick context so I calibrate the analysis:**

1. **Primary conversion goal** — what's the main action you want visitors to take? (Free trial signup, demo request, waitlist, etc.)
2. **Traffic source** — mostly organic/SEO, paid ads, direct/branded, referral, or a mix? This matters a lot for message match.
3. **Current numbers** — what's your conversion rate now, and what are you hoping to hit?
4. **What happens after this page** — do they land straight into a signup form, a multi-step flow, a demo booking calendar?
5. **Any existing data** — heatmaps, session recordings, or user feedback that hint at where people drop off?
6. **What's been tried already** — so I don't recommend something you've already tested and ruled out.

Once I can see the page, I'll break it down across value prop clarity, headline, CTA hierarchy, trust signals, objection handling, and friction points — then give you Quick Wins, High-Impact Changes, and Test Ideas, plus alternative headline/CTA copy.

If it's easier, you can also just paste the raw copy section-by-section (hero, features, social proof, etc.) and I'll work from that.
