# Decisive

**Question:** Does the output make a clear call, on reasoning that holds up?

## Great (2)
- Leads with the answer: the main culprit, the wedge, or the recommendation.
- Says why it chose that answer, in one or two lines.
- When it asks questions, shows which way the answer goes for each possible reply.
- Offering options counts as decisive only when it maps each option to its condition AND says which one it would pick with what's known.

## OK (1)
- Makes a pick, but it is buried, hedged, or buried under context.
- Makes a pick on weak reasoning, such as choosing a wedge only because a competitor is weak there.
- Lists options with pros and cons but does not rank them.
- Maps options to their conditions but does not say which it would pick.

## Bad (0)
- Offers several options with no pick.
- Says "it depends" without saying on what.
- Hands the decision back to the user when it had enough to decide.
- Lists options with no recommendation and no conditions.

## Edge cases
- Asking questions is not indecision if a provisional pick is given too.
- Positioning tasks only: the pick is the wedge, and no wedge means Decisive cannot be a 2. Other tasks do not need a wedge.
