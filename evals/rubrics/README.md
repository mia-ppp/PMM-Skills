# Rubrics (v2)

Four dimensions grade every skill output. Each is scored Great (2), OK (1), or Bad (0).
v2 is rewritten from Mia's hand-grading of A-01 to A-10.

| Dimension | Question it answers |
|---|---|
| [Grounded](grounded.md) | Does it stay true to the input and say what it assumed? |
| [Decisive](decisive.md) | Does it make a call on solid reasoning? |
| [Usable](usable.md) | Could a senior PMM act on it with light edits? |
| [Sharp](sharp.md) | Does it say something general best practice would not? |

## The provisional rule

When information is missing, a good output does not stall. It answers provisionally:
1. Gives its best answer with what it has.
2. States every assumption explicitly.
3. Ends with the two or three questions whose answers would change the recommendation.

Answering before asking is fine. Answering on hidden assumptions is not.

## Grading rules

- **Score each dimension on its own.** A grounded answer can still be indecisive.
- **When torn between two tiers, pick the lower one.**
- **Write a one-line reason for every score.** Quote the output where possible.
- **Length is not quality.** Comprehensive is not the same as sharp.
- **Grade the output, not the prompt.** A vague prompt does not excuse a vague answer.

## Anchors

Anchors come from A-01 to A-10 only. A-11 to A-20 are the holdout and must never become anchors.
