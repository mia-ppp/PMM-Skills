# Visual Style

Use the user's Ramp case study deck as a style reference if `Ramp_Case_Study_Deck.pptx` is placed in this folder. Use it for visual style only. Do not reuse its claims, data, wording, or content.

Treat these colors as approximate. The user may adjust them:

| Use | Color |
|---|---|
| Background | Warm off-white, approximately `F7F4EE` |
| Header rows | Dark brown, approximately `34251F` |
| Highlight and selected option | Copper, approximately `B86B45` |
| Main text | Deep brown, approximately `2D2723` |
| Secondary text | Muted brown-gray, approximately `766D66` |
| Table rules | Light warm gray, approximately `DDD5CC` |

Each slide uses this structure:

1. Eyebrow label.
2. Claim headline.
3. Optional one-line subline.
4. Main content, usually one table or one three-step visual.
5. Key-insight band at the bottom.
6. Slide number at bottom right.

Do not add accent lines under titles or decorative stripes. Use whitespace, a clear type scale, subtle table rules, dark header rows, and copper highlights to create hierarchy. Keep slide copy short and legible at presentation size.
