# Creative briefs and authentic product visuals

The originating channel owner remains accountable for audience, objective, message, proof, delivery and review. Read this only when visuals or video materially support the artifact.

## Brief

Specify buyer question, intended action, approved narrative, proof sources, placement, format/length, accessibility, budget, rights/consent, production owner and acceptance criteria.
Use real current-product screenshots or approved mockups explicitly labeled as conceptual. Never generate UI and present it as shipped functionality. Remove sensitive customer data and obtain usage permission.

## Narrative and storyboard

For demos: buyer problem, authentic workflow, first value, supported outcome, next action. For explainers: problem, category context, product mechanism, evidence, CTA.
Write a scene table with timing, spoken script, on-screen text, product state/source, visual/action and caption/transcript requirements. Avoid unsupported performance claims or implied roadmap availability.
For organic social scripts use the social-content owner; paid scripts use ad-creative; sales demos use sales-enablement; product announcement narrative uses product-communications; page/explainer copy uses marketing-copy.

## Production handoff

External design/video/toolkit capabilities own rendering, editing, compression and deployment. If useful, consult [image toolkit](media-production/image/guidance.md) or [video toolkit](media-production/video/guidance.md), checking current capabilities and permissions. Tool choice does not change PMM ownership or authorize publishing.
Review actual output for authentic product truth, proof, brand, legibility, captions, accessibility and required channel constraints. Route originating-requirement review to output-quality-check and approved-meaning review to messaging-consistency-audit.
